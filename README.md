# HR Analytics Dashboard — Power BI

An interactive **HR Analytics dashboard built in Power BI** to analyze employee demographics, workforce structure, compensation, satisfaction, and employee attrition.

The project uses a simulated dataset of **1,000 employees** and demonstrates data preparation with **Power Query**, analytical calculations using **DAX**, and interactive dashboard development.

## Dashboard Pages

### 1. HR Overview

* Total employees
* Attrition count and attrition rate
* Active employees
* Average monthly income
* Attrition by department
* Income by department
* Employee distribution by department and age group

### 2. Demographics & Workforce

* Gender distribution
* Age group analysis
* Education distribution
* Employees by job role
* Average income by job role
* Marital status analysis
* Workforce filtering using interactive slicers

### 3. Attrition Drivers

* Attrition by overtime
* Attrition by job satisfaction
* Attrition by tenure
* Attrition by income band
* Attrition by business travel
* Attrition by distance from home
* Attrition by department and job role

## Tools & Technologies

**Power BI | Power Query | DAX | Microsoft Excel**

## Key Skills Demonstrated

* Data cleaning and transformation
* Calculated columns
* DAX measures
* KPI development
* Data visualization
* Interactive slicers and filtering
* Workforce and attrition analysis
* Dashboard design
* Business-focused data analysis

## Dataset

The dataset contains **1,000 employee records and 20 original fields**, covering demographics, employment, compensation, satisfaction, performance, work patterns, career growth, and attrition.

Additional analytical columns such as **Age Group, Tenure Group, Income Band, and Distance Group** were created during the Power Query transformation stage.

## Important Note

This is a **simulated dataset created for learning and portfolio purposes**. The attrition patterns and compensation figures are designed for analytical practice and should not be interpreted as real company HR statistics.

## Project Objective

The objective of this project is to demonstrate how Power BI can be used to transform raw employee data into an interactive HR dashboard that helps users explore workforce composition and identify patterns associated with employee attrition.
